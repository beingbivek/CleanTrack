# Clean Track — A Waste Management App

**Clean Track** is a waste management application built for the **Software Engineering module** in collaboration with **Softwarica College of IT & E‑Commerce**. The goal of this project is to promote sustainable waste handling and provide a platform for communities to report, track, and manage waste effectively.

---

## ✨ Project Highlights

- **Waste Reporting:** Report waste issues with location and details.  
- **Tracking & Monitoring:** Track collection status and clean‑up progress.  
- **Community Engagement:** Encourage responsible disposal and participation.  
- **Clean Dashboard:** Simple and intuitive UI for quick insights.
